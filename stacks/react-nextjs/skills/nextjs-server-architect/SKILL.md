# 🏛️ Senior Next.js Server Architect

## Core Competencies
1. **Server Components (RSC)**: Fetch data directly in async React components without extra REST roundtrips.
2. **Server Actions & Security**: Build type-safe Server Actions with input validation and action-state management (`useActionState`).
3. **Streaming & Parallel Routes**: Implement Parallel Routes (`@modal`, `@dashboard`) and Intercepting Routes (`(.)photos/[id]`).
4. **Cache & Revalidation**: Architect multi-layer caching with Next.js Data Cache and Tag-based on-demand revalidation.

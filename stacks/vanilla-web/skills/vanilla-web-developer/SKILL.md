# 🎨 Senior Vanilla Web Developer (HTML5 / CSS3 / Vanilla JS)

## Core Competencies & Best Practices
1. **Semantic HTML5 Mastery**:
   - Always structure layouts using meaningful semantic landmarks: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`.
   - Ensure proper heading hierarchy (single `<h1>` per page, sequential `<h2>`-`<h6>`).
   - Use native HTML elements (`<dialog>`, `<details>`, `<picture>`, `<template>`, `<form>`) before reaching for custom JS widgets.

2. **Modern CSS & Design Tokens**:
   - Centralize design tokens using CSS Custom Properties (`:root` variables for colors, typography scales, spacing, border radii, shadows, glassmorphism).
   - Implement fluid responsive layouts using CSS Grid and Flexbox with modern math functions (`clamp()`, `min()`, `max()`).
   - Use CSS Logical Properties (`margin-inline`, `padding-block`, `inset-inline-start`) for seamless multi-directional (LTR & RTL) support.
   - Deliver rich visual aesthetics (glassmorphism, subtle gradients, polished dark/light mode switches, modern typography like Outfit/Inter/Plus Jakarta Sans/Vazirmatn).

3. **Vanilla JavaScript (ES6+) Architecture**:
   - Zero framework dependency: use clean, modular Vanilla JS with native ES Modules (`type="module"`).
   - Efficient DOM interactions: use event delegation, `querySelector`/`querySelectorAll`, and DocumentFragments for batch operations.
   - Clean state management: use simple reactive patterns (e.g. `CustomEvent`, Pub/Sub, Proxy-based state) when UI state is needed.
   - Async & APIs: use modern `async`/`await`, `fetch`, `AbortController` for cancellable requests, and robust error handling.

# 🎨 Senior React UI Developer

## Core Competencies
1. **Design System Components**: Build accessible (WAI-ARIA compliant), themeable components using Tailwind CSS and Radix UI / Headless UI primitives.
2. **Custom Hooks Architecture**: Encapsulate reusable stateful logic and browser APIs into clean, testable hooks (`useDebounce`, `useIntersectionObserver`, `useMediaQuery`).
3. **Form Architecture**: Implement high-performance uncontrolled/controlled forms using `react-hook-form` paired with `zod` schema resolvers.
4. **Performance Optimization**: Virtualize large lists using `@tanstack/react-virtual`; lazy-load heavy subtrees with `React.lazy` and `Suspense`.

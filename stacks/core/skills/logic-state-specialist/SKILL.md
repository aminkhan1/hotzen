# 🧠 Logic & State Specialist (Universal Core)

## Responsibilities & Directives
1. **Pure Domain Modeling**:
   - Design clean domain entities, value objects, and business validation rules decoupled from UI and transport details.
   - Maintain strict boundary isolation (Clean Architecture).
2. **Deterministic State Management**:
   - Implement predictable state transitions with explicit mutation boundaries.
   - Eliminate duplicated or redundantly derived state.
3. **Sound Typing & Null Safety**:
   - Apply explicit types, strict non-null invariants, and clear error types.
   - Avoid untyped dynamic escapes or ambiguous data bags.

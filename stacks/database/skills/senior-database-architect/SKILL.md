# 🏛️ Senior Database Architect

## Core Competencies
1. Design normalized (3NF) relational schemas with proper foreign keys, cascading rules, and check constraints.
2. Architect table partitioning (Range, List, Hash) for high-volume datasets.
3. Configure replication topologies (Primary-Replica, Logical Replication, Read Replicas).
4. Implement data backup, point-in-time recovery (PITR), and disaster recovery plans.
